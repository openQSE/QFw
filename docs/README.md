# QFw Documentation

This directory keeps user-facing documentation separate from development
records and release material.

- [Usage](usage.md) describes common build, configuration, and execution
  workflows.
- [Requirements](requirements/) records QFw behavior and acceptance criteria.
- [Design](design/) records architecture and implementation-oriented design.
- [Recipes](recipes/) provides task-oriented operational procedures.
- [Release](release/) records release notes, manifests, and source-change
  summaries.
